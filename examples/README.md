# Пример: рекламный пост GigaChat → после правки

Учебный пример. Черновик написан в манере коротких промо-постов GigaChat специально для демонстрации, это не чужой текст.

**Черновик** ([draft.txt](draft.txt)):

> 🚀 Друзья, отличные новости! Наш онлайн-курс по Python для начинающих стартует 1 ноября!
>
> Вы узнаете:
> ✅ как писать первые программы;
> ✅ как работать с данными;
> ✅ как автоматизировать рутину.
>
> Занятия проходят два раза в неделю, стоимость — 4 900 рублей в месяц. Таким образом, курс является отличной возможностью сделать первый шаг в IT! Переходите по ссылке и записывайтесь прямо сейчас! [ссылка]

**После правки** ([result.txt](result.txt)):

> Наш онлайн-курс по Python для начинающих стартует 1 ноября. На курсе пишем первые программы, работаем с данными и автоматизируем рутину.
>
> Занятия проходят два раза в неделю, стоимость 4 900 рублей в месяц. Курс — отличный первый шаг в IT. Записывайтесь по ссылке.

**Что изменилось и почему** (шаг 3 SKILL.md, профиль `gigachat`):
- сняты эмодзи, «!», «Друзья, отличные новости» и тизер «Вы узнаете:» со списком — это рекламная рамка, у коротких постов GigaChat её снятие давало +19 пунктов у слепого судьи;
- все факты на месте: дата, три пункта программы, расписание, цена, оценка курса, призыв;
- «Таким образом, … является» заменено обычной фразой — книжная связка и канцелярит в финале характерны для GigaChat;
- заглушку `[ссылка]` в текст не ставим: ссылку автор вставляет сам.

**Что сказал скрипт** ([check_output.txt](check_output.txt)): один флаг A9 — текст короче черновика на 18%. Правило шага 2 разрешает в коротком промо-посте снять рамку целиком, даже если она больше 10% текста, поэтому правку оставляем. Скрипт — помощник, а не цель: на первых прогонах он поймал реальные ошибки правки (добавленное «можно», срезанный призыв, лишнюю «ё»), и их пришлось исправить.
